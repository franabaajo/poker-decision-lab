# 0001 — Scope and purpose

**Status:** Accepted (2026-10-31)

## Context
The project is a portfolio piece demonstrating probability, simulation, statistics and software engineering, weighted towards data science / quantitative trading roles.

## Decision
Build an educational analyser for a single heads-up Texas Hold'em decision: facing one bet, call or fold. It is not a real-money tool, does not connect to live games, and always states that results depend on assumed opponent behaviour.

## Out of scope for the MVP
Hero raising, game-theory solvers, multiway pots, tournament ICM, full hand-history backtesting.
